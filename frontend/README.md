# BookVisually Frontend

Interactive bookkeeping canvas built with React Flow.

## Setup

```bash
npm install
```

## Development

Make sure the backend is running first:

```bash
# In backend/ directory
mix phx.server
```

Then start the frontend:

```bash
npm run dev
```

Open http://localhost:5173

## Features

- Visual canvas with draggable nodes
- Account management (create, deposit)
- Real-time balance updates
- Dashboard summary
- Interactive node-based interface
