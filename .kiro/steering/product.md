# Product Overview

BookVisually is an interactive bookkeeping application that transforms financial transactions into visual diagrams. Users record transactions as nodes and watch money flow in real time through an interactive interface.

## Core Features

- Visual transaction recording with node-based interface
- Real-time money flow visualization
- Expense and income tracking
- Financial totals displayed visually
- Event-driven financial engine for scalability

## Target Use Case

Simplifying bookkeeping through visual, interactive diagrams rather than traditional spreadsheet-based accounting.
