# bookvisually
BookVisually turns bookkeeping into interactive diagrams. Record transactions as nodes, watch money flow in real time, and track expenses, income, and totals visually. Built with Elixir for a scalable, event-driven financial engine.

## Project Structure

This is a monorepo containing:

- **`frontend/`** - React + Vite + Tailwind CSS + React Flow for interactive diagrams
- **`backend/`** - Elixir + Phoenix + PostgreSQL for the financial engine

## Frontend

Located in the `frontend/` folder at the root of the project.

**Stack:**
- React (JavaScript, no TypeScript)
- Vite
- Tailwind CSS
- React Flow (@xyflow/react)

**Commands:**
```bash
cd frontend
npm install
npm run dev
```
